# Danaher (danaher)
Danaher Corporation is a global life sciences and diagnostics conglomerate whose operating companies include Beckman Coulter, Leica Microsystems, Cepheid, SCIEX, IDT, Cytiva, Abcam, Aldevron, Radiometer, and others. Danaher itself does not publish a corporate-level developer API; product and service APIs are provided by individual operating companies under the Danaher portfolio.
